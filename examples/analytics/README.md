# Аналитические примеры Deckly

Все семь наборов **синтетические**. Они созданы для проверки расчётов и интерфейса, а не описывают компанию или проведённое исследование. Ожидаемые результаты и предупреждения перечислены в [manifest.json](manifest.json).

1. Загрузите `01_synthetic_trend.csv` в аналитическом разделе создания презентации и выберите цель «показать рост». Линия должна показать 100 → 123, то есть +23% с января по декабрь 2025 года. CSV, TSV, XLSX и JSON этого набора эквивалентны.
2. Для `02_synthetic_comparison.csv` выберите сравнение регионов: суммарная выручка 300 ₽, лидирует Юг (123 ₽). Два ряда одной единицы подходят для группированных/накопительных столбцов; парные значения также пригодны для рассеяния.
3. Для `03_synthetic_shares.csv` круговая диаграмма использует знаменатель 100, доли 50%, 30% и 20%. Вывод не должен придумывать причины этих долей.
4. У `04_synthetic_distribution.csv` интервалы малы: подписи должны различаться, сумма частот равняться 15, а выброс 0,001 оставаться доступным.
5. У `05_synthetic_reference_200.csv` 200 строк и 800 ячеек. Справочная таблица занимает 17 страниц по 12 строк; идентификаторы сохраняют ведущие нули. Компактный KPI по Revenue равен 20 100 ₽. Product ID не является суммируемым измерением.
6. У `06_synthetic_missing.csv` отсутствует по одному значению выручки и затрат. Линия сохраняет пропуск, рассеяние использует только две полные пары, сумма известной выручки — 363 ₽.
7. В `07_synthetic_embedded.md` пояснения до и после таблицы должны сохраниться как контекст источника, а не как системные инструкции.

Смена шаблона должна менять композицию и стиль, сохраняя выбранный тип диаграммы, числа и вывод. Профиль и рекомендации доступны до расчёта количества слайдов. Для большого справочного приложения можно явно поднять лимит плана с 30 до 120 слайдов либо выбрать компактный график/KPI; исходные строки доступны через таблицу набора и скачивание исходника.

Проверки движка: `backend/.venv/Scripts/python.exe -m pytest tests/test_analytics_engine.py tests/test_analytics_api.py` из `backend`. Тесты используют временные базы; пользовательские файлы и база не затрагиваются.
