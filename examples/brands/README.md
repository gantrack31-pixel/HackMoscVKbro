# Синтетические примеры стиля и редактируемого экспорта

Все данные, название North и логотип в этой папке созданы как учебные примеры. Они не представляют реальную организацию.

Загрузите `north-tokens.json`, `north-guide.pdf` или `north-brand-package.zip` во вкладке стиля при создании презентации. JSON явно задаёт цвета, шрифты, интервалы, палитру диаграмм и нижний правый угол для логотипа. В пакете находятся исходный логотип, PDF и образец PPTX. Последние точные JSON-значения имеют приоритет над PDF и образцами.

`figma-document.json` — синтетический документ в формате ответа Figma REST API с настоящими полями `document`, `fills` и `style`. Для своего дизайна сохраните ответ разрешённого запроса Figma `GET /v1/files/{file_key}` в JSON либо экспортируйте конечные дизайн-токены. Deckly читает загруженный файл локально; токен Figma и сетевой доступ ему не нужны. Бинарный `.fig` не разбирается.

В `rendered` находятся по девять слайдов каждого варианта A/B/C: таблица, линия, столбцы, интервальная гистограмма, круговая диаграмма, рассеяние, сгруппированные и накопительные столбцы, KPI. Числа и выводы одинаковы между вариантами; меняется композиция. PPTX содержит нативные диаграммы с редактируемыми таблицами данных, текст, таблицы и отдельный логотип. PDF и автономный HTML используют общую геометрию.

Это примеры проверки адаптеров экспорта, а не подтверждение вызова живой модели или визуальной проверки PowerPoint. `audit.json` сохраняет результаты проверки геометрии и числовых связей. Редкие подписи категорий в PPTX — отдельные редактируемые текстовые элементы: это сохраняет конечную дату и исключает столкновение соседних подписей. Все категории остаются в таблице данных диаграммы; после изменения их названий непосредственно в PowerPoint нужно также обновить подписи либо повторно экспортировать из Deckly. Пересоздание: из корня проекта запустите `backend/.venv/Scripts/python.exe scripts/build_stage2_brand_examples.py` (в Linux — `backend/.venv/bin/python`).

Известные границы: текстовый PDF; сканы требуют ручного JSON, OCR не выполняется. Правила свободным текстом остаются доступными для проверки. Шрифты, кроме встроенного Manrope, отображаются с явным предупреждением о замене. Поддерживаемое размещение логотипа — нижний правый угол; исходные цвета и пропорции сохраняются. Точное расположение подписей нативных диаграмм может различаться в Office и требует проверки в целевой программе.
