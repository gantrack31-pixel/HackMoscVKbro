# Локальная демонстрация с изолированными данными

Из корня проекта: `node scripts/qa/record-demo.mjs`.

Нужны установленный frontend (`pnpm --dir frontend install`), браузер Playwright, backend `.venv` и уже запущенный локальный сайт с актуальным `frontend/dist`. По умолчанию статические файлы берутся с `http://127.0.0.1:8003`; другой адрес задаётся `DECKLY_QA_STATIC_URL`. Путь Python можно задать через `DECKLY_QA_PYTHON`.

Worker не открывает сетевой порт. Он запускает настоящий FastAPI TestClient с новой временной SQLite и storage. Все `/api/` запросы браузера, включая бинарные загрузки, направляются в worker. Ответы генерации и экспорта не подменяются. Внешние ключи, облачная база, почта и интеграции отключены; работает настоящий деморежим. Пользовательская база сервера, раздающего статику, не участвует.

Запись, скриншоты и файлы перезаписываются только в `examples/outputs/acceptance`. Временные каталоги имеют префикс `deckly-acceptance-` в системной временной папке и содержат лишь синтетические тестовые материалы. Транспорт через stdio измеряется отдельно от обычного HTTP; результат не является производственным сетевым бенчмарком.

Исходные диагностические сценарии и отчёты сохранены в `examples/outputs/evidence`; некоторые старые сценарии содержат абсолютные пути тестовой сессии. Они являются журналом выполненной проверки, а не универсальной командой установки приложения.
