Приоритеты: P0 — критический, P1 — высокий, P2 — средний, P3 — низкий. P0 не найдено: нет повреждённых PPTX, потери данных, доступа к чужим проектам или «успешного» результата без файла.

## P1

### BUG-01. Шлюз провайдера обрывает непотоковые LLM-запросы на ~51 с — большие презентации не генерируются
- **Где:** `backend/app/services/llm.py`, `complete_json` (запрос без `stream`).
- **Шаги:** live-режим, VK AI Space; запросить структуру на 20 слайдов с данными (сценарий D1) или 15 слайдов (C1).
- **Ожидаемо:** структура возвращается.
- **Фактически:** `RemoteProtocolError: Server disconnected without sending a response` ровно через 51,0–51,2 с. Автоповтор снова обрывается, и пользователь видит «Не удалось подключиться к LLM». D1: 0 из 3 попыток; C1: 1 из 2.
- **Доказательство:** `artifacts/logs/provider-timeout-experiment.txt` — один и тот же запрос с длинным ответом: без потока обрыв на 51,2 с, с `stream=true` — успешно за 168,7 с (3726 фрагментов). Логи: `artifacts/logs/live-backend.log` («connection dropped after 51.1s»); `artifacts/live/C1-try1`, `D1-try1`, `D1-try2`, `D1`.
- **Примечание:** отдельные вызовы оформления длительностью 95 с прошли, то есть обрыв срабатывает не всегда (зависит от узла шлюза), но для структуры 15–20 слайдов он доминирует.

### BUG-02. Многосерийная аналитика (grouped) не генерируется: заголовок с хвостовым пробелом
- **Где:** генерация заголовка grouped-плана в аналитическом модуле; сравнение в `analytics_store.validate_requested_analytics` (строка 112). Модель `Slide` обрезает пробелы.
- **Шаги:** загрузить `inputs/company_2023_2025.csv` в `/api/analysis/upload` → рекомендация `grouped` (выручка и расходы по годам) → `PUT selection` → `POST plan` → передать план в `/api/generate`.
- **Ожидаемо:** задание создано.
- **Фактически:** HTTP 409 «Вывод аналитического слайда изменён. Сохраните проверенный заголовок или пересчитайте анализ.». Заголовок плана `'2025: Выручка_млн_руб — 220, Расходы_млн_руб — 145 '` при приёме превращается в строку без пробела и перестаёт совпадать.
- **Доказательство:** `artifacts/analytics/title-whitespace-matrix.txt` (только grouped даёт `trailing_space=1`), `artifacts/analytics/types/results.json`.
- **Влияние:** самый частый аналитический сценарий («выручка и расходы по годам») недоступен.

### BUG-03. Переполнение текста в узлах схем и карточках иконок попадает в итоговые файлы
- **Где:** `services/visuals.py` (`diagram_nodes`, `pictogram_nodes`) и подгонка в `layout.py`.
- **Шаги:** сценарий B1, вариант B, слайды 4 и 9.
- **Ожидаемо:** текст внутри блоков.
- **Фактически:** подписи выходят за нижнюю границу блоков («и абстракций», «результата», «ошибки: механизм обучения», «экспертизы»). Это видно и в PDF-экспорте продукта, и в PowerPoint. Аудит регистрирует `error:overflow` (B1-b: 11, A1-b: 4, A2-b: 4), но результат публикуется без автоисправления.
- **Доказательство:** `artifacts/visual/B1/B1-b-slide04-hires.png`, `B1-b-slide09-hires.png`, `B1-a-slide04-pdf-vs-powerpoint.png`, `artifacts/live/B1/audit-b.json`.

### BUG-04. Модель не использует фотографии из шаблонов, даже когда об этом прямо просят
- **Шаги:** A1 «...фотографии из доступных материалов шаблона» на шаблоне «Приют для животных» (52 ассета, 30 пригодных изображений); A2 «Используй доступные изображения»; B2 «природные фотографии».
- **Ожидаемо:** слайды `kind=image` с `template_asset_id`.
- **Фактически:** 0 слайдов `image` во всех 6 успешных живых колодах. Движок при этом корректно вставляет фото шаблона (синтетические `IMG-pack-*` — PASS).
- **Связанное:** `/api/templates` отдаёт метаданные шаблонов из набора без `assets` и с устаревшими полями — они обновляются только внутри `get_template` при генерации.
- **Доказательство:** `artifacts/live/*/summary.json` (поле `kinds`), `artifacts/synthetic/results.json`.

## P2

### BUG-05. Отказ генерации структуры из-за «чисел не из источника» в описательных презентациях
- **Шаги:** B2 (12 слайдов, экология).
- **Фактически:** «Не удалось собрать структуру после двух попыток... Причина: Слайд 12: В тексте есть числа, которых нет в источнике: 2, 3». Модель пишет количества и сроки («через 2 недели», «2–3 преимущества»), проверка их справедливо отклоняет, а на починку есть только одна попытка. B2: 1 отказ из 2.
- **Доказательство:** `artifacts/live/B2-try1/summary.json`.

### BUG-06. Импорт брендбука не работает на macOS
- **Где:** `services/brand_worker.py`, строка 10: `resource.setrlimit(RLIMIT_AS, 512 МБ)` бросает `ValueError: current limit exceeds maximum limit`. Перехватывается только `ImportError` (Windows). `brand_style.py` глушит stderr, и пользователь видит невнятное «Не удалось безопасно разобрать стиль».
- **Проверено:** на macOS падает; в Docker (Linux, одноразовый `docker run --rm`) тот же JSON разбирается успешно.
- **Влияние:** 8 падений pytest на macOS; локальная разработка и запуск без Docker на Mac.

### BUG-07. Шрифт Manrope не встраивается в PPTX — в PowerPoint геометрия расходится с превью
- **Фактически:** `typeface="Manrope"` в слайдах, частей `ppt/fonts/` нет. Без установленного Manrope PowerPoint подставляет другой шрифт с другой шириной, и переполнения из BUG-03 усиливаются. Аудит выдаёт по 10 замечаний `font_fallback` на колоду.
- **Доказательство:** `artifacts/visual/B1/B1-a-slide04-pdf-vs-powerpoint.png`.

### BUG-08. Повторы и отсутствие графиков в аналитической презентации (LLM-путь)
- **Шаги:** C1 с двумя CSV, 15 слайдов.
- **Фактически:** 0 диаграмм (3 таблицы, 9 текстовых слайдов). Данные по регионам повторены на слайдах 7, 11 и 13, сводная таблица — на 5 и 12. KPI-карточки не созданы. Все числа при этом верны.
- **Доказательство:** `artifacts/live/C1/project.json`, `artifacts/visual/C1/C1-a-contact-sheet.png`.

### BUG-09. Качество профилирования и заголовков в аналитическом модуле
- Единицы из имени столбца не извлекаются (`Выручка_млн_руб` → `unit: ""`), в заголовках показаны сырые имена с подчёркиваниями.
- «Год» распознан как `identifier`, а не как время.
- Рекомендованный pie по годам даёт «2025: 43,564356% от 505» (6 знаков после запятой, сомнительная семантика).
- KPI «Сумма: Выручка_млн_руб — 505» складывает выручку разных лет.
- **Доказательство:** `artifacts/analytics/company-dataset.json`, `title-whitespace-matrix.txt`.

### BUG-10. Схемы: диагональные соединители и неверная структура
- Процесс из 4–5 узлов переносится на вторую строку с диагональной стрелкой через схему: B1 слайд 2, C2 слайды 12 и 15, синтетика `D-process`, шаблоны 3:4.
- Модель выбирает иерархию для последовательности: «Нейросети: архитектура» (B1 слайд 4), соединитель пересекает схему.
- **Доказательство:** `artifacts/visual/B1`, `artifacts/visual/C2`, `artifacts/visual/custom-3x4`.

### BUG-11. Однообразные текстовые слайды
- Доля `text` в живых колодах 30–61% (A1 3/5, A2 3/7, B1 3/10, B2 4/12, C1 9/15, C2 11/18): растёт с объёмом. Типичный текстовый слайд — абзац и 3–5 пунктов мелким текстом в левой половине при пустой правой.
- В варианте B на каждом слайде одинаковая акцентная панель с крупным номером.
- **Доказательство:** контактные листы `artifacts/visual/C2/C2-b-contact-sheet.png`, `A1`, `C1`.

### BUG-12. Автотесты частично не проверяют то, что заявлено
- `tests/conftest.py` задаёт `LLM_MODEL=''`, `LLM_BASE_URL=''`; после коммита `47c0e03` (переход на Inference API) `configured()` в этих тестах ложно, и они падают с «Модель ещё не подключена»: `test_live_generation` (2), `test_regeneration` (2), `test_regeneration_style_recovery`, `test_workflow::test_llm_mock_success_and_errors`, `test_ai_operations::test_provider_pool...`.
- `test_hardening::test_redesign_retries_format_and_lossless_shorthand` ожидает 2 вызова оформления, а их теперь 4 (параллельные варианты, коммит `72456ff`).
- E2E, вероятно дефекты самих тестов:
  - `generation-recovery` — регистрируется через API на уже открытой странице и переходит по хэшу без перезагрузки;
  - `requirements:3` — strict-локатор находит 2 input с `type=file`;
  - `presentation-polish` — допуск 2 px против 2,59 px;
  - `hardening:37` — ширина кнопок 132,03 против 131,33.
- **Доказательство:** `artifacts/auto/backend-pytest*.txt`, `artifacts/auto/e2e/*`.

### BUG-13. E2E `smartart`: после сохранения редактор показывает ложный конфликт «Презентация изменилась в другой вкладке» (требует расследования)
- **Шаги (E2E):** мастер в demo-режиме → сменить тип первого слайда на схему, перебрать типы → «Сохранить» → перезагрузить. Все действия блокируются, `Проверить` неактивна.
- **Ручное воспроизведение** (live, проект через API, второй слайд) **не подтвердило** дефект: сохранение 200, черновик очищен, после перезагрузки «Сохранено». Падение стабильно и на коде до последних изменений.
- **Доказательство:** `artifacts/auto/e2e-failures/smartart/error-context.md`, `artifacts/ui/conflict-*.png`.
