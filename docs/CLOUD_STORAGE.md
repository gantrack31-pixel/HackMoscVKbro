# Сохранение в облако

В редакторе нажмите **Завершить → В облако → Сохранить в облако**.
Сервер сохраняет содержание презентации, композицию, исходный материал и библиотеку доступных пользователю шаблонов, включая бинарные PPTX. Скачивание PPTX/PDF/HTML доступно на том же экране.

## Подключение

1. Создайте PostgreSQL в выбранном сервисе (например, Supabase или Neon) либо используйте существующую БД.
2. В `backend/.env` задайте `CLOUD_DATABASE_URL` — строку подключения PostgreSQL из кабинета сервиса. Пароль не добавляется в React, Git или адрес страницы. Для специальных символов в пароле используйте URL-кодирование.
3. Установите зависимости из `backend/requirements.txt` и перезапустите FastAPI. Для удалённого соединения используйте проверку TLS, рекомендованную провайдером; пример с системными корневыми сертификатами:

```dotenv
CLOUD_DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DB?sslmode=verify-full&sslrootcert=system
```

Первое подключение создаёт схему `deckly_private` из `backend/app/services/cloud_schema.sql`. Серверному пользователю PostgreSQL нужны права на создание схемы и таблиц; альтернативно администратор применяет SQL заранее и выдаёт серверу доступ к этим таблицам. Схема не предназначена для публичного REST-доступа браузера.

Проверка TLS и параметры соединения: [документация PostgreSQL](https://www.postgresql.org/docs/current/libpq-ssl.html). Фиксация и откат транзакций: [документация Psycopg](https://www.psycopg.org/psycopg3/docs/basic/transactions.html).

## Поведение

- Успех возвращается после COMMIT PostgreSQL. Ошибка соединения не заменяется локальным «облачным» сохранением.
- Доступ ограничен владельцем из серверной сессии. Данные другого аккаунта не доступны через API.
- Повторное сохранение того же содержания не создаёт лишнюю версию. Новое содержание обновляет облачную копию; более старая локальная версия не перезаписывает более свежую облачную.
- В разделе «Мои презентации» облачная копия восстанавливается в отдельный проект вместе с файлом исходного шаблона. Локальный проект не перезаписывается.
- Локальные аккаунты, сессии и рабочие проекты пока остаются в SQLite. PostgreSQL хранит облачные копии и шаблоны. Удаление рабочего проекта не удаляет резервную облачную копию.
- Чтобы пользоваться одним аккаунтом с других устройств, нужен доступный этим устройствам сервер Deckly. Само подключение БД не публикует локальный сайт в интернете.

## Проверка реального подключения

Для интеграционного теста задайте `TEST_CLOUD_DATABASE_URL` на **отдельную тестовую БД**, затем выполните в `backend`:

```powershell
.venv/Scripts/python.exe -m pytest tests/test_experience.py -q
```

Проверяются сохранение/чтение исходного PPTX, изоляция владельцев, повторное сохранение и откат транзакции. Без тестового адреса этот тест пропускается явно. Остальные тесты проверяют API, предпросмотр, исправления, экспорт и обработку ошибок облака.
