## Как читать результаты

- **Подтверждено** — непосредственно наблюдается в текущем коде, конфигурации, репозитории или запущенной проверке.
- **Ограничение** — известная граница продукта, не обязательно дефект.
- **Проверить** — есть основание для проверки, но данных недостаточно, чтобы объявить это багом или ненужным элементом.
- **Рекомендация** — предлагаемое действие с критерием завершения.

Приоритеты: **P0** — до публичного развёртывания/если затронуты данные; **P1** — важное повышение надёжности; **P2** — плановое улучшение; **P3** — только после подтверждения потребности.

В документах ниже не повторяются как невыполненные функции те механизмы, которые уже описаны в проектной документации и покрыты тестами. Результаты тестов относятся к локальному запуску этой проверки, а не к любому окружению или внешнему провайдеру.
