# Модель и соответствие ТЗ

По умолчанию используется демонстрационный режим без LLM. Он позволяет проверить интерфейс, БД, парсер, аудит и экспорт без API-ключа. Создание произвольного содержания требует включения `LLM_MODE=live`.

В `.env.example` указана Qwen/Qwen3-32B как пример модели с открытыми весами: 32.8B параметров, Apache 2.0. Модель не скачана и не запущена на этом компьютере. Проверьте доступность у своего провайдера и фактическое имя endpoint. Источник: [официальная карточка модели](https://huggingface.co/Qwen/Qwen3-32B).

Формат API совместим с сервером vLLM `/v1/chat/completions`. Сервер отправляет промпт, исходный материал и JSON-схему, валидирует структуру и при ошибке схемы даёт одну попытку исправления. Полная сборка и пересборка ограничены 300 секундами, включая очередь; структура, помощник, изображения и отдельная смысловая проверка — общим лимитом `AI_OPERATION_TIMEOUT_SECONDS` (по умолчанию 240 секунд). Каждый запрос к текстовой модели дополнительно ограничен `LLM_TIMEOUT_SECONDS` (180 секунд по умолчанию). Скрытые рассуждения по умолчанию отключаются для OpenRouter и локальных Qwen3-совместимых серверов; явные параметры провайдера сохраняются. Отмена, лимиты токенов по задачам и тайминги описаны в [AI_OPERATIONS.md](AI_OPERATIONS.md). Исторический прогон 27.09.2026 занял 33,72 секунды; это измерение на конкретном брифе, а не гарантия скорости провайдера. Подробности — в [VALIDATION.md](VALIDATION.md).

Из ТЗ учтены: отдельная структура, три оформления одного содержания, три предоставленных шаблона, обработка неизвестного PPTX, редактируемые объекты, аудит с выбранными исправлениями, документация и отдельные промпты. Девять сочетаний «3 шаблона × 3 оформления» проверяются тестами.

Для финальной сдачи ещё нужны: прогон на материале организаторов и визуальная проверка нативного PPTX в PowerPoint, особенно сложных мастеров. Генерация изображений через FLUX.1-schnell подготовлена отдельно, но сервис изображений в текущем прогоне не подключён; инструкция — в [REQUIREMENTS.md](REQUIREMENTS.md). Если команда проходит в этап, где ТЗ требует модель VK, замените провайдера и модель по правилам организаторов. Лицензию и лимит параметров проверяйте для фактически используемой модели, а не только примера в `.env`.
