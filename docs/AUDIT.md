# Что проверяет аудит

Правила вычисляются из сохранённых данных и координат, а не из случайных результатов или таймера.

| Проверка | Метод | Исправление |
|---|---|---|
| Выход объекта за слайд | Прямоугольник против размеров сцены | Вручную |
| Переполнение текста | Высота перенесённых строк против высоты блока | Вручную |
| Контраст | Относительная яркость: 3:1 для крупного текста, 4.5:1 для обычного | Тёмный заголовок по выбору |
| Плотность тезисов | Больше шести пунктов или пункт длиннее 15 слов | Вручную |
| Таблица | Высота строк текста против высоты ячейки | Вручную |
| Диаграмма | Единица измерения и длина подписей | Вручную |
| Служебный текст | Lorem ipsum, TODO, «вставьте текст» | Вручную |
| Источник | Нормализация пробелов и точное вхождение цитаты | Пользователь проверяет смысл |
| Смысл | Отдельный запрос подключённой LLM | Вручную |

Автоисправление применяется только к выбранным доступным замечаниям и создаёт версию. Поддельные или уже неактуальные идентификаторы замечаний отклоняются. В редакторе можно вернуть предыдущую версию.

Совпадение цитаты не доказывает истинность утверждения и не означает, что тезис логически следует из неё. Оценки LLM помечены отдельно от правил. Геометрия исходной графики мастера в проверки не входит; это ограничение показывается рядом с предпросмотром.

Нулевое число замечаний означает только отсутствие проблем по доступным правилам. Не заявляется полная проверка дизайна или фактов.
