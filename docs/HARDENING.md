## Контракты и ограничения

- Ответ оформления — `a/b/c → slides → {slide, design}`; enum определяет Pydantic.
  Допускаются только без потерь преобразуемые сокращения (список вместо `slides`, плоские поля design).
  Неоднозначный JSON, повтор ключей, NaN, незакрытые reasoning-теги и обрезанный JSON отвергаются.
  Исправление не использует `eval` и не придумывает недостающие значения.
- Привязка источника: `chunk_id`, `start`, `end`, `quote`. Позиции — Unicode code points,
  конец не включён. ID меняется при изменении источника. Точная цитата не означает смысловую истинность.
  Непроверяемое замечание имеет `grounding=unverified`; отсутствующий источник/провайдер — `unavailable`.
- История хранит по 12 состояний, включая вариант оформления. Пустое сохранение не очищает Redo.
  Несохранённый ручной черновик защищён существующими блокировками UI и версионной проверкой AI.
- Полный исходный ZIP сохраняется без изменений и скачивается с проверкой доступа владельца.
  `metadata.package.parts` индексирует каждую часть; media за пределами первых 12 слайдов больше не теряются.
  XML мастеров/макетов, шрифтовые ресурсы, векторы, фоновые заливки и градиенты остаются в оригинале.
  В экспортируемом PPTX выбранные нативные картинки используют исходные байты, а не PNG-превью.
- **Это не 100% PowerPoint-рендерер.** Произвольные SmartArt, анимации, векторные форматы и графика
  исходных обычных слайдов не обещают полного воспроизведения в созданной колоде или браузере/PDF.
  Сохраняется оригинал; неподдерживаемый media-объект остаётся в каталоге без веб-превью.
  Ограничения защиты ZIP остаются включены. Превью: 512 px, 200 KB/картинку и 8 MB суммарно;
  примеры текста — первые 12 слайдов; контекст модели ограничен отдельно, vision — до 4 картинок.
- AutoFit — приближение по измерению текста, не алгоритм Microsoft. Шрифты исходника сохранены для PPTX;
  браузер/PDF по-прежнему используют Manrope. При достижении минимального кегля переполнение не скрывается:
  оно остаётся замечанием аудита. Точную вёрстку сторонних шрифтов проверяйте в PowerPoint.
- Prompt isolation снижает риск инъекций, но не даёт математической гарантии поведения модели.
  Дополнительные границы: JSON/Pydantic, scope разрешённых слайдов, локальные ID ресурсов,
  отсутствие ключей/путей в prompt payload и бинарных изображений в текстовой смысловой проверке.
