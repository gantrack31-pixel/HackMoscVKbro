Ограничения вынесены отдельно:

- В текущей локальной конфигурации `LLM_MODE=demo`, ключ модели отсутствует. Проверены протокол, числовые ограничения и управляемые ответы модели в тестах; качество свободных ответов живой модели не оценивалось.
- PowerPoint и LibreOffice локально отсутствуют. PPTX проверен повторным чтением, структурой диаграмм и встроенными данными; это не проверка открытия в Office без предупреждения о восстановлении. Для точного составного превью PPTX без собственной миниатюры нужен совместимый рендерер; интерфейс честно показывает отсутствие превью.
- Бинарный `.fig` не поддерживается. Рабочая альтернатива — JSON документа Figma или экспорт дизайн-токенов. PDF-сканы требуют ручного извлечения текста: OCR нет. Нераспознанные правила не выдаются за применённые.
- Для одинакового отображения используется встроенный Manrope с явным предупреждением о замене другого шрифта. Поддержанное правило размещения логотипа — нижний правый угол; остальные остаются на ручную проверку.
- Подписи категорий нативных диаграмм PPTX — отдельные редактируемые текстовые элементы. После переименования категорий непосредственно в PowerPoint их нужно обновить отдельно или экспортировать презентацию заново.
- Контейнер Docker в этой среде не запускался. Зависимости разбора перечислены в backend/requirements.txt, шрифты находятся в backend, Dockerfile устанавливает LibreOffice/Poppler. Это проверка состава, а не подтверждение работы собранного контейнера.
- Метрики сняты в локальном headless Chromium с программным SwiftShader при параллельных проверках. Их нельзя считать производственными Core Web Vitals. Переход на главную с 3D остаётся дороже обычных разделов; корректное освобождение ресурсов проверено.
