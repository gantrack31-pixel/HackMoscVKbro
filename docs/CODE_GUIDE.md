# Как читать код Deckly

Пример: пользователь нажимает «Создать структуру».

1. В `frontend/src/pages/Wizard.tsx` функция `outline()` читает выбранный шаблон, материал и число слайдов из React-состояния.
2. `frontend/src/api.ts` отправляет JSON на `/api/outline`. Сессионная cookie отправляется браузером, CSRF-токен добавляется в заголовок. API-ключа модели в этом файле нет.
3. Маршрут в `backend/app/main.py` проверяет аккаунт и доступ к шаблону, затем вызывает `services/llm.py`.
4. Сервер читает ключ из `.env`, отправляет запрос модели и проверяет ответ через Pydantic-модели из `models.py`.
5. React получает массив слайдов и отображает редактируемую структуру. На этом этапе PPTX ещё не создаётся.
6. «Создать презентацию» отправляет согласованную структуру. `layout.py` размещает её в трёх вариантах; `export.py` строит редактируемые объекты PowerPoint. LLM не переписывает содержание повторно.

## Где что менять

| Хочу изменить | Файл |

| Дизайн верхней панели, вкладок и профиля | `styles/refinements.css` |
| Девять новых тем и их палитры | `backend/app/services/theme_catalog.py` |
| Карточку шаблона | `components/TemplateCard.tsx` |

| Поля редактора и сохранение | `pages/Editor.tsx` |

| Размещение слайдов | `backend/app/services/layout.py` |
| Правила проверки | `backend/app/services/audit.py` |
| PPTX/PDF/HTML | `backend/app/services/export.py` |

`useState` хранит временное состояние формы. Данные не попадут в SQLite, пока не отправлен запрос API. Объект `content` — содержание презентации, а `scene` — координаты фигур и текста. Это разделение позволяет менять композицию без переписывания фактов.

`App.tsx` выбирает экран по URL после `#` и хранит открытую презентацию. `Shell.tsx` рисует общее меню. Страницы собраны из обычных React-компонентов; HTML задаётся через JSX, оформление находится в отдельных CSS-файлах. Никаких серверов Node.js в проекте нет.

Чтобы изменить дизайн после Figma: выберите экран, найдите его компонент в таблице, перенесите размеры и цвета в CSS. Сначала измените один компонент, выполните `pnpm build` и проверьте экран в браузере. Прямой синхронизации Figma → React здесь нет.
