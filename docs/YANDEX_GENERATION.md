# Архив: генерация через Yandex AI Studio

Генерация переведена на OpenRouter. Актуальные параметры и проверки:
[OPENROUTER_TEMPLATE_UPDATE.md](OPENROUTER_TEMPLATE_UPDATE.md).
Yandex ID по-прежнему используется для входа; это отдельная настройка.

Настройки читаются из `backend/.env` **той папки, из которой запущен сервер**. `.env.example` — только публичный образец; действующие ключи туда не вставлять. После изменения `.env` перезапустите сервер. Не запускайте одновременно старую копию приложения на том же порту.

```dotenv
LLM_MODE=live
LLM_BASE_URL=https://ai.api.cloud.yandex.net/v1
LLM_API_KEY=<секретный API-ключ>
YANDEX_FOLDER_ID=<идентификатор каталога>
LLM_MODEL=gpt://<идентификатор каталога>/yandexgpt/latest
LLM_JSON_MODE=false
LLM_TIMEOUT_SECONDS=180
LLM_MAX_TOKENS=9000
```

Каталог также извлекается из полного URI модели, если `YANDEX_FOLDER_ID` не задан. Для Яндекса сервер отправляет `Authorization: Api-Key …` и `OpenAI-Project`; для остальных совместимых провайдеров сохранён Bearer. См. [официальный пример Yandex AI Studio](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-basic).

1. Материалы открываются пустыми. «Пример Deckly.Ai» явно отправляет пример модели с выбранными количеством слайдов и аудиторией. «Создать структуру» отправляет собственный текст пользователя.
2. Модель подготавливает структуру с учётом аудитории. Пользователь может отредактировать текст и порядок без новых запросов к модели.
3. «Создать презентацию» вызывает модель снова: один запрос возвращает три отдельных плана оформления `a/b/c` для всех слайдов. Текст, утверждённый на шаге структуры, сохраняется. Сервер проверяет планы, собирает редактируемые PPTX и проверяет геометрию всех трёх вариантов. Модель выбирает оформление; координаты и экспорт вычисляет сервер, не исполняя произвольный код модели.
4. «Новая композиция» требует непустых пожеланий. Пустое поле блокируется в UI и API до обращения к модели. Новые планы сохраняются отдельной презентацией; прежняя остаётся доступной. При некорректном ответе допускается одна попытка исправления формата, затем показывается ошибка, без подмены результатом demo.

Проверено 27.09.2026: реальное соединение с Яндексом, структура на 3 слайда для клиентской аудитории, три разных плана, повторное оформление с конкретными правками; исходный текст сохранён. Геометрические ошибки в исходной тестовой презентации не обнаружены. Это не гарантирует безошибочность любого ответа модели: содержание и замечания аудита следует просмотреть перед экспортом. Автоматические тесты используют изолированные настройки без настоящих ключей; живые проверки выполнялись отдельно на синтетическом материале.
