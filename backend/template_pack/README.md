# Пак презентаций

24 исходных PPTX из предоставленного пользователем архива. Файлы сохранены без
изменений; SHA-256 и исходные имена находятся в `manifest.json`.

Подборка появляется в общей галерее в категории «Пак презентаций» при запуске
приложения. Повторный запуск не создаёт дубликаты. Это общие ресурсы приложения,
а не личные загрузки пользователя. При переносе проекта пути обновляются.

Forest и Startup содержат только тему и макеты, без готовых слайдов. Обложки для
них показывают титульный макет с названием темы. У Every и Blockchain первые
страницы рекламные: для обложек выбраны слайды 3 и 2 соответственно, что указано
в предпросмотре. Остальные обложки показывают первый слайд исходника.
Обложки отрендерены LibreOffice 26.2.6 в WebP шириной 1600 px.
Полный разбор геометрии, цветов и графики выполняется
при выборе шаблона; галерея использует компактный индекс и готовые обложки.

В `source-notes` сохранены авторские инструкции и архивы шрифтов из пакета.
Они не устанавливаются и не исполняются приложением. Авторство и условия
использования исходных материалов остаются у их авторов.
